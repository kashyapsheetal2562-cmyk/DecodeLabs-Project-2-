# DecodeLabs Project 2 – Backend API Development

A simple REST API developed as part of the DecodeLabs Full Stack Development Internship Program.

## 📌 Project Overview

This project focuses on building a basic backend API using Node.js and Express.js.

The API handles user data, accepts client requests, validates input, and returns structured JSON responses with appropriate HTTP status codes.

## 🚀 Features

- GET API endpoint to retrieve all users
- GET API endpoint to retrieve a single user
- POST API endpoint to create a new user
- Basic input validation
- Email format validation
- JSON request and response handling
- Proper HTTP status codes
- Error handling for invalid requests
- Simple REST API structure

## 🛠️ Technologies Used

- Node.js
- Express.js
- JavaScript
- REST API
- JSON
